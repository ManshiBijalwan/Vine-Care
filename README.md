# Vine-Care

Precision viticulture platform for KOKOTOS ESTATE.

## Repo structure

```
vine-care/
├── mobile-app/   # Flutter app (Android + iOS) — VineCare mobile client
└── web-app/      # Backend (Django microservices) + web frontend
```

### mobile-app/

Flutter app for VineCare. Currently runs on demo/mock data; see
`mobile-app/HOW_TO_RUN.md` for setup and `mobile-app/VineCare_Flutter_Technical_Documentation.docx`
for full architecture docs.

### web-app/

Backend (Django microservices on AWS EC2) and web frontend. To be added.

- Web app: see [`web-app/README.md`](web-app/README.md)
